# Минимальный размер оплаты труда (МРОТ) в Российской Федерации

## Описание
Данный датасет содержит исторические данные о величине минимального размера оплаты труда (МРОТ) в России с 2015 по 2026 год. МРОТ является ключевым социальным показателем, влияющим на расчет пособий, налогов и заработных плат.

## Особенности для гибридной модели
1. **Ступенчатый характер**: Изменения происходят скачкообразно (обычно 1 января, иногда дополнительные индексации в середине года).
2. **Влияние политики**: Решения о повышении принимаются правительством на основе инфляции и бюджетных возможностей.
3. **Экспертный контекст**: Для точного прогноза на 2025-2026 годы критически важно учитывать официальные заявления властей и принятые федеральные законы, что делает этот датасет идеальным для тестирования LLM-эксперта.

## Источники
- Федеральные законы о внесении изменений в статью 1 Федерального закона "О минимальном размере оплаты труда".
- Официальные данные Росстата.
- Справочные системы (Гарант, КонсультантПлюс).
