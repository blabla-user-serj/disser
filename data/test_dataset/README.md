# Тестовый набор данных: Ключевая ставка ЦБ РФ

## Описание данных

**Показатель**: Ключевая ставка Банка России (% годовых)

**Источник данных**: Официальный сайт Центрального банка Российской Федерации  
**URL**: https://www.cbr.ru/hd_base/keyrate/

**Описание**: Ключевая ставка — это процентная ставка, по которой Центральный банк предоставляет кредиты коммерческим банкам на срок одна неделя и под залог ценных бумаг. Она является основным инструментом денежно-кредитной политики и влияет на:
- Стоимость кредитов для бизнеса и населения
- Ставки по депозитам
- Курс рубля
- Уровень инфляции

## Структура файлов

### 1. `key_rate_train.csv` - Обучающий набор данных
- **Период**: 28.02.2022 — 28.10.2024
- **Количество записей**: 15 точек данных
- **Формат**: CSV с колонками `Дата,Значение`
- **Назначение**: Для обучения моделей прогнозирования

### 2. `key_rate_test.csv` - Тестовый набор данных
- **Период**: 20.12.2024 — 06.06.2025
- **Количество записей**: 5 точек данных
- **Формат**: CSV с колонками `Дата,Значение`
- **Назначение**: Для проверки качества прогноза (эти данные НЕ должны использоваться при обучении)

## Особенности временного ряда

1. **Нерегулярная частота**: Ставка меняется по решению Совета директоров ЦБ РФ (примерно 8 заседаний в год)
2. **Дискретные изменения**: Ставка меняется ступенчато, обычно на 0.5-2.0 п.п.
3. **Экстремальные события**: 
   - Резкий рост до 20% в феврале 2022 (специальная военная операция)
   - Быстрое снижение до 7.5% к сентябрю 2022
   - Новый цикл повышения с июля 2023 до 21% в октябре 2024
4. **Макроэкономическая обусловленность**: Зависит от инфляции, курса рубля, экономической ситуации

1. **Для обучения модели** используйте только `key_rate_train.csv`
2. **Для проверки качества** сравнивайте прогноз с `key_rate_test.csv`
