# Датасеты: Социальные процессы в России (2010–2023)

Все данные получены из официальных российских и международных источников (Росстат, СФР, Мировой банк).  
**Никакой экстраполяции или синтетических данных не используется.**

## Структура

Каждый датасет разделён на:
- `*_train.csv` — обучающая выборка (2010–2019, n=10 наблюдений)
- `*_test.csv` — тестовая выборка (2020–2023, n=4 наблюдения)
- `expert_references.json` — ссылки для LLM-эксперта (только в пределах тренировочного периода ≤ 2019)

---

## Датасет 1 — Уровень безработицы (% МОТ)
**Файлы:** `dataset1_unemployment_train.csv`, `dataset1_unemployment_test.csv`  
**Источник:** Росстат, обследование рабочей силы (методология МОТ)  
**Колонки:**
| Колонка | Описание |
|---|---|
| `year` | Год |
| `unemployment_rate_pct` | Уровень безработицы, % от рабочей силы (15+) |

**Динамика:** постепенное снижение с 7.4% (2010) до 4.6% (2019), COVID-скачок до 5.8% (2020), рекордный минимум 3.2% (2023).  
**Почему хорошо предсказывается:** монотонный тренд снижения + сезонность отсутствует в годовых данных → SARIMA / XGBoost.

---

## Датасет 2 — Естественный прирост/убыль населения (тыс. чел.)
**Файлы:** `dataset2_natchange_train.csv`, `dataset2_natchange_test.csv`  
**Источник:** Росстат, «Естественное движение населения»  
**Колонки:**
| Колонка | Описание |
|---|---|
| `year` | Год |
| `births_thous` | Число родившихся, тыс. чел. |
| `deaths_thous` | Число умерших, тыс. чел. |
| `nat_change_thous` | Естественный прирост/убыль, тыс. чел. |

**Динамика:** переход от убыли к приросту (2013–2015), затем нарастающая убыль; COVID дал катастрофический провал −1 039 тыс. (2021).  
**Почему хорошо предсказывается:** чёткий нисходящий тренд `nat_change_thous` с 2016 → SARIMA/Hybrid хорошо уловят тренд.

## Датасет 3 — Численность пенсионеров и средняя пенсия
**Файлы:** `dataset3_pensioners_train.csv`, `dataset3_pensioners_test.csv`  
**Источник:** Росстат (urov_p2.htm), Социальный фонд России (СФР)  
**Колонки:**
| Колонка | Описание |
|---|---|
| `year` | Год |
| `pensioners_mln` | Численность пенсионеров, млн чел. |
| `avg_pension_rub` | Средний размер назначенной пенсии, руб./мес. |

**Динамика:** `pensioners_mln` — рост до 43.9 млн (2018), затем снижение из-за пенсионной реформы (повышение возраста с 2019).  
**Почему хорошо предсказывается:** стабильный монотонный тренд до точки перегиба; `avg_pension_rub` — плавный рост → оба хорошо аппроксимируются.

## Датасет 4 — Уровень бедности (% населения ниже ПМ)
**Файлы:** `dataset4_poverty_train.csv`, `dataset4_poverty_test.csv`  
**Источник:** Росстат, «Уровень жизни населения»  
**Колонки:**
| Колонка | Описание |
|---|---|
| `year` | Год |
| `poverty_pct` | Доля населения с доходами ниже ПМ, % |
| `poor_population_mln` | Численность малоимущих, млн чел. |
| `poverty_threshold_rub` | Граница бедности (ПМ), руб./мес. |

**Динамика:** снижение с 12.5% (2010) до 12.3% (2019) с пиком 13.4% в кризисном 2015 г.  
**Почему хорошо предсказывается:** слабый нисходящий тренд + выброс в 2015 → интересный тест для устойчивости модели.

---

## Датасет 5 — Ожидаемая продолжительность жизни при рождении (лет)
**Файлы:** `dataset5_lifeexp_train.csv`, `dataset5_lifeexp_test.csv`  
**Источник:** Росстат / Мировой банк (worldbank.org)  
**Колонки:**
| Колонка | Описание |
|---|---|
| `year` | Год |
| `life_exp_total` | ОПЖ, оба пола, лет |
| `life_exp_male` | ОПЖ, мужчины, лет |
| `life_exp_female` | ОПЖ, женщины, лет |

**Динамика:** стабильный рост с 68.8 (2010) до 73.3 (2019), сильный COVID-шок (−2.0 лет в 2020, −3.2 лет в 2021), быстрое восстановление до 73.4 к 2023.  
**Почему хорошо предсказывается:** устойчивый линейный тренд в тренировочный период → SARIMA и Hybrid дадут точный прогноз.

## Ссылки для LLM-эксперта

Файл `expert_references.json` содержит ссылки на официальные источники, ограниченные данными **до 2019 года включительно** (тренировочный период).  
Это позволяет LLM-эксперту обращаться к актуальному историческому контексту, не нарушая принцип hold-out теста.

**Все ссылки ведут на:**
- rosstat.gov.ru — официальный Росстат
- sfr.gov.ru — Социальный фонд России
- gogov.ru — агрегатор официальных данных Росстата
- svspb.net — исторические таблицы (Мировой банк / Росстат)
- demoscope.ru — Демоскоп Weekly (НИУ ВШЭ)
